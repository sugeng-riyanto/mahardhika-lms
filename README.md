# AKADEMI Digital Campus — Agentic AI Documentation Pack

This folder is the implementation control pack for a custom school LMS built with React + TypeScript + Tailwind + Vite, Django REST Framework, and Supabase PostgreSQL/Auth/Storage.

## How the agent must start

1. Read `AGENTS.md`.
2. Read `TIMELINE_DECEMBER.md` and the active scope files.
3. Read product, architecture, data, API, RBAC, native interactive-engine, annotation-canvas, essay-assessment, and skills documents.
4. Read `ACCEPTANCE_CRITERIA.md`, `AGENTIC_WORKFLOW.md`, and `DEPLOYMENT_CHECKLIST.md`.
5. Inspect the actual repository and record any conflict before implementation.

## Definition of complete

“Complete by December” means the approved v2 scope is deployed, tested, documented, migrated, trained, monitored, recoverable, and signed off for controlled school production. It does not mean feature parity with every commercial LMS or unlimited scale.

Coursera, Edpuzzle, H5P, Moodle, and Canvas LMS are inspiration sources only. The implementation is native and requires none of their credentials or runtimes.

## Faster completion

The timeline is a maximum schedule. Agents are explicitly allowed to complete gates and move forward early. Passing evidence—not elapsed time—controls progression.
